## 💬 Key Terms (For Reference)

- **Canonical URL** - Tells Google which version of page to index
- **Schema/JSON-LD** - Structured data helps Google understand content
- **OG Tags** - Open Graph tags for social media previews
- **Meta Description** - Summary shown in search results (155 chars)
- **Robots.txt** - File that tells search engines what to crawl
- **Sitemap.xml** - Map of all pages on your site
- **Hreflang** - Tag for multi-language versions
